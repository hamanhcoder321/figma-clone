# Final Review

Trước khi kết thúc một task, nếu Developer yêu cầu review:

Kiểm tra:

## Figma
- layout
- spacing
- typography
- image
- color
- effect

## Structure
- component
- layout
- constants
- naming
- duplication

## Responsive
- desktop
- tablet
- mobile
- overflow

## Code
- TypeScript
- semantic HTML
- maintainability
- unnecessary hard-code

## Performance
- image usage
- unnecessary client-side JavaScript
- unnecessary React usage

## Rule
Không sửa code trong quá trình review nếu Developer chỉ yêu cầu review.

Phải báo:

- lỗi
- mức độ
- nguyên nhân
- hướng sửa

Chỉ sửa khi Developer yêu cầu.
